# Calculator App 🧮

A simple calculator built using HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations (+, -, ×, ÷)
- Clear button (C)
- Answer button (Ans)
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How it works
- Click numbers to input values
- Choose an operator
- Press "=" to get result
